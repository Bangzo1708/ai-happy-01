A small friendly white robot and a laughing little girl blow one giant soap bubble together in a sunny garden. The robot holds the bubble wand with glowing crescent happy eyes and an open smile; the girl, eyes squeezed shut in laughter, blows beside it; between them floats a huge iridescent bubble catching the golden afternoon light and holding a tiny rainbow. The idea is a shared moment of pure, specific joy — two unlikely friends, one enormous bubble, one afternoon — rather than a generic happy scene: the warmth is in the laughter and the teamwork, the delight is in the bubble itself, and the whole picture reads at a glance even at 300 px, with no text in the image.

`main.ts` is a Node 22 program (standard library only) that copies the bundled `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output` inside the grader's container). Deterministic, no network, no model call, no API key. `entry.png` is the image: JPEG bytes, 1024×1024 px, 262,248 bytes, within the 1 MiB / 1024×1024 limits.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
